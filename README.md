# Sales Performance Analysis of Walmart Stores Using Advanced SQL Techniques

## Project Overview

This project analyzes Walmart sales data using advanced SQL techniques to uncover meaningful business insights. The analysis focuses on branch performance, product profitability, customer segmentation, payment preferences, and sales trends.

## Objectives

- Identify the branch with the highest sales growth.
- Find the most profitable product line in each branch.
- Segment customers based on spending behavior.
- Detect anomalies in sales transactions.
- Determine the most popular payment method by city.
- Analyze monthly sales by gender.
- Identify the best product line for each customer type.
- Detect repeat customers.
- Find top customer categories by sales volume.
- Analyze sales trends by day of the week.
